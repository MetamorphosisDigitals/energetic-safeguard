PRIVACY & SECURITY BOUNDARY

Privacy and security stay narrow.

The billing integration stores only the evidence needed to project optional continuity—not the user’s inner life.

WHAT THE SYSTEM PROTECTS

Minimal, server-owned evidence

SECRETS

Stripe secret key, signing secret, and price IDs exist only in protected server configuration.

IDENTITY

Customer and subscription identifiers map through the authenticated application user, never client-supplied IDs.

ARCHIVE

Cloud routine plans remain user-owned, individually restorable, organizable, and deletable.

WHAT THE SYSTEM EXCLUDES

Nothing beyond the billing boundary

CARD DATA

Payment methods and card details remain with Stripe’s hosted checkout and billing portal.

METADATA

Checkout metadata carries only internal user and plan identifiers—not reflections, notes, or ritual content.

ACCESS

A payment problem never removes ritual access or suppresses a safety handoff.

OWNERSHIP RULE

The user can see, restore, organize, and delete their cloud plan copies without changing their local device copies.
