# Routine Cloud Backup UI Review

## Verified states

The authenticated desktop and mobile captures show the Routine History Backup panel after the existing private plan archive. The panel makes the local-first boundary clear, surfaces the explicit **Back up this device** action, presents the optional automatic-backup preference, and lists a concise account-history summary.

On desktop, the manual action, preference, and cloud record sit in a readable horizontal hierarchy. On the mobile capture, the action stacks below the status, the automatic preference remains legible, and the latest cloud record stays visible without horizontal overflow. The existing Daily Routine, private archive, and safety actions remain reachable around the new panel.

## Outcome

The panel is ready for the full test and build validation. It preserves an explicit-consent path for first backup and clearly distinguishes device-only records from account-backed history.
