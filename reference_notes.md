# Prior-Version Reference Notes

The reviewed prior version uses a deliberately quiet, centered onboarding flow on a warm paper background. Screen one presents a compact brand mark, the product name, the three-line positioning statement, a small step indicator, and clearly separated Skip and Continue actions. Screen two explains the app’s decision model through four calm, icon-led rows: feeling, situation, available time, and preferences.

The current app should carry forward the **single-supportive-practice framing**, restrained progression indicator, and strong one-action focus. It should retain the current **The Energetic Safeguard** name, rose-compass branding, structured content model, payment flow, and more editorial dashboard rather than copying the prior implementation.

The third onboarding screen presents all five practice styles as generous, descriptive radio cards and explicitly explains that the selection is a default which remains changeable in Settings or within a pathway. The current app should adopt this clear default-setting explanation and preserve the stated choice that physical crystals are never required.

The current live preview rendered the new onboarding entry successfully. A subsequent direct browser-view request timed out in the connected browser extension, so responsive screenshot validation and the passing type/test checks remain the primary verification evidence for this update.
